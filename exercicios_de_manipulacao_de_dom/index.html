Exercícios de Manipulação da Árvore DOM

Exercício 1: Alterando o Conteúdo de um Elemento

Para praticar a busca e modificação de elementos na tela, considere o cenário em que existe um título principal com texto desatualizado. Dada a estrutura HTML descrita a seguir, escreva o código JavaScript necessário para selecionar o elemento com o identificador "titulo-boas-vindas" e alterar seu conteúdo textual para "Bem-vindo ao Curso de Desenvolvimento de Sistemas!". 

<div id="container">
    <h1 id="titulo-boas-vindas">Texto Inicial...</h1>
</div>

Resposta:

Texto Inicial...

Código JavaScript da solução:

document.getElementById("titulo-boas-vindas").textContent =
    "Bem-vindo ao Curso de Desenvolvimento de Sistemas!";

Explicação:

Utilizamos o método document.getElementById() para localizar o elemento HTML pelo seu identificador "titulo-boas-vindas". Em seguida, utilizamos a propriedade textContent para substituir o conteúdo textual original pelo novo texto solicitado no enunciado.

Exercício 2: Criando e Adicionando Elementos Dinamicamente

A criação de elementos em tempo de execução é fundamental para interfaces dinâmicas. Considerando uma lista de tarefas vazia ou parcialmente preenchida, crie uma função em JavaScript chamada adicionarItem que receba um parâmetro do tipo texto. Essa função deve criar um novo item de lista e anexá-lo ao final da lista não ordenada que possui o identificador "lista-tarefas". 

<h2>Minha Lista de Tarefas</h2>
<ul id="lista-tarefas">
    <li>Estudar sintaxe básica do JS</li>
</ul>

Resposta:

Minha Lista de Tarefas

  • Estudar sintaxe básica do JavaScript
<h2>Minha Lista de Tarefas</h2>
<ul id="lista-tarefas">
    <li>Estudar sintaxe básica do JS</li>
</ul>

Conteúdo do arquivo js/script.js:

function adicionarItem(texto) {
    const novoItem = document.createElement("li");
    novoItem.textContent = texto;

    document.getElementById("lista-tarefas").appendChild(novoItem);
}

document.getElementById("btn-adicionar").addEventListener("click", function() {
    const campo = document.getElementById("nova-tarefa");

    if (campo.value.trim() !== "") {
        adicionarItem(campo.value);
        campo.value = "";
    }
});

Explicação:

Utilizamos document.createElement("li") para criar um novo item de lista. A propriedade textContent define o texto desse item, e o método appendChild() adiciona o novo elemento ao final da lista identificada por "lista-tarefas".

Também utilizamos addEventListener() para executar a função quando o botão for clicado. O campo é verificado para evitar a inclusão de tarefas vazias.

Exercício 3: Alternando e Alterando Estilos CSS com classList

A alteração visual de componentes no navegador deve ser feita prioritariamente por meio de classes CSS. Com base na estrutura a seguir, escreva um script em JavaScript para selecionar o elemento contêiner com o identificador "painel", remover a classe "oculto" para torná-lo visível e aplicar a classe "destaque" para modificar sua apresentação visual. 

<style>
    .destaque {
        background-color: #fef08a;
        border: 2px solid #eab308;
        padding: 12px;
    }

    .oculto {
        display: none;
    }
</style>

<div id="painel" class="oculto">
    <p>Mensagem importante para o usuário!</p>
</div>

Resposta:

Mensagem importante para o usuário!

Código JavaScript da solução:

const painel = document.getElementById("painel");

painel.classList.remove("oculto");
painel.classList.add("destaque");

Explicação:

Utilizamos document.getElementById("painel") para localizar o elemento HTML. O método classList.remove("oculto") remove a classe que mantém o painel escondido, tornando-o visível. Em seguida, classList.add("destaque") adiciona a classe responsável pela cor de fundo, borda e espaçamento do painel.

Exercício 4: Remoção de Elementos da Árvore

O gerenciamento da árvore de elementos exige a capacidade de excluir nós desnecessários. Dada a lista de notificações mostrada no código HTML abaixo, desenvolva uma função em JavaScript denominada removerPrimeiraNotificacao. Essa função deve localizar a lista pelo seu identificador "notificacoes" e remover apenas a primeira notificação contida nela sempre que for executada. 

<ul id="notificacoes">
    <li id="notif-1">Notificação 1: Atualização de sistema</li>
    <li id="notif-2">Notificação 2: Novo e-mail recebido</li>
    <li id="notif-3">Notificação 3: Lembrete de aula</li>
</ul>

Resposta:

  • Notificação 1: Atualização de sistema
  • Notificação 2: Novo e-mail recebido
  • Notificação 3: Lembrete de aula

Código JavaScript da solução:

function removerPrimeiraNotificacao() {
    const lista = document.getElementById("notificacoes");

    if (lista.firstElementChild) {
        lista.removeChild(lista.firstElementChild);
    }
}

document.getElementById("btn-remover-notificacao")
    .addEventListener("click", removerPrimeiraNotificacao);

Explicação:

Utilizamos document.getElementById("notificacoes") para localizar a lista de notificações. A propriedade firstElementChild identifica o primeiro elemento da lista. Em seguida, removeChild() remove esse elemento.

A condição if verifica se ainda existe algum item na lista, evitando tentar remover um elemento quando a lista estiver vazia. O método addEventListener() faz a função ser executada quando o botão for clicado.

Exercício 5: Manipulação com Eventos de Clique

A interatividade em aplicações web é alcançada pela captura de ações do usuário. Utilizando a estrutura HTML abaixo, construa um script em JavaScript que escute o evento de clique do botão com o identificador "btn-exibir". Ao ser acionado, o script deve capturar o texto digitado no campo de entrada com o identificador "campo-nome" e exibir uma mensagem personalizada dentro do parágrafo com o identificador "resposta". 

<div>
    <input type="text" id="campo-nome" placeholder="Digite seu nome">
    <button id="btn-exibir">Exibir Mensagem</button>
    <p id="resposta"></p>
</div>

Resposta:

Código JavaScript da solução:

document.getElementById("btn-exibir").addEventListener("click", function() {
    const nome = document.getElementById("campo-nome").value;

    document.getElementById("resposta").textContent =
        "Olá, " + nome + "! Seja bem-vindo(a)!";
});

Explicação:

Utilizamos o método addEventListener() para escutar o evento de clique do botão identificado por "btn-exibir". Quando o botão é acionado, a propriedade value captura o texto digitado no campo "campo-nome". Em seguida, a propriedade textContent exibe uma mensagem personalizada no parágrafo identificado por "resposta".
